# 更多图腾 (More Totems)

我的世界基岩版 Add-on，新增 **19 种图腾**。

## 安装
1. 在 [Releases](../../releases) 下载 `MoreTotems.mcaddon`，双击导入。
2. 创建/编辑世界，同时启用**行为包**和**资源包**。
3. 需要游戏版本 **1.26.10 及以上**（使用了 `entityHurt` 前置事件，`@minecraft/server` 2.6.0）。

## 图腾列表

### 致命伤害触发型（拿在主手/副手，挡下致命一击后消耗）
与原版一致：虚空和 `/kill` 无法抵挡；手上有原版不死图腾时优先用原版。

| 图腾 | 效果 | 合成（无序） |
|---|---|---|
| 替死图腾 | 挡下致命伤害，离你最近的一个生物替你死（不含玩家，默认放过宠物） | 不死图腾 + 蜘蛛眼 + 发酵蛛眼 |
| 凤凰图腾 | 满血，防火 60 秒，力量，点燃周围 6 格生物 | 不死图腾 + 烈焰棒 + 岩浆膏 |
| 生命图腾 | 满血，再生 III，伤害吸收 IV | 不死图腾 + 金苹果 |
| 回城图腾 | 传送回重生点 | 不死图腾 + 末影珍珠 + 指南针 |
| 末影图腾 | 主世界中随机闪现 16–32 格，周围生物失明 | 不死图腾 + 末影之眼 + 紫颂果 |
| 雷霆图腾 | 对周围最多 6 个生物降下闪电，你获得防火 | 不死图腾 + 避雷针 + 紫水晶碎片 |
| 冰霜图腾 | 周围 8 格生物缓慢 IV + 虚弱 II | 不死图腾 + 浮冰 + 雪球 |
| 复仇图腾 | 对攻击者造成 30 点伤害，你获得力量 II | 不死图腾 + 铁剑 + 火药 |
| 守护图腾 | 抗性 IV，伤害吸收 V，击飞周围生物 | 不死图腾 + 盾牌 + 铁锭 |
| 三命图腾 | 可挡 3 次致命伤害 | 3 × 不死图腾 + 钻石 |

### 持有生效型（拿在主手或副手即生效，不消耗）
合成：2 金锭 + 1 绿宝石 + 下表材料（无序）。

| 图腾 | 效果 | 材料 |
|---|---|---|
| 疾风图腾 | 速度 II + 跳跃提升 | 糖 |
| 深海图腾 | 水下呼吸 + 海豚的恩惠 | 海晶碎片 |
| 夜视图腾 | 夜视 | 金胡萝卜 |
| 狂战图腾 | 力量 II + 急迫 II | 烈焰粉 |
| 飞羽图腾 | 缓降 + 跳跃提升 II | 羽毛 |
| 烈焰图腾 | 防火 | 岩浆膏 |
| 饱食图腾 | 缓慢补充饥饿值 | 面包 |
| 磁吸图腾 | 吸取 7 格内的掉落物 | 铁锭 + 红石 |
| 治愈图腾 | 再生 I | 闪烁的西瓜片 |

数值与开关可在 `behavior_pack/scripts/main.js` 顶部的 `CONFIG` 和各图腾定义中修改。

## 开发
```bash
pip install pillow
python3 tools/generate.py   # 重新生成物品、配方、语言文件、像素图标，并打包到 dist/MoreTotems.mcaddon
```
图标由 `tools/generate.py` 以 16×16 像素手绘数据生成。清单里的 UUID 请勿更改，否则玩家无法覆盖升级。
